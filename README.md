# Planning F890

Application de planning du magasin Boulanger Flers F890 (SAS ANA).

- `index.html` : espace gestionnaire (planning équipe, roulements, demandes, compteurs, export paie)
- `moi.html` : espace collaborateur (planning personnel, demandes de congés, échanges, erreurs)
- `firestore.rules` : règles de sécurité à coller dans Firebase > Firestore > Règles

Aucune donnée n'est stockée dans ce dépôt : tout est dans Firebase (projet planning-890).
